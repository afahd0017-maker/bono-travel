# BONO TRAVEL website starter

## Included
- Responsive custom HTML/CSS/JavaScript site
- English, Arabic, Turkish, Italian and Russian language switcher
- Experience cards and WhatsApp enquiry links
- No build step or paid dependency required

## Preview locally
Open `index.html` in a browser. For a more reliable local preview, use VS Code with the Live Server extension.

## Before publishing
1. Confirm the WhatsApp number in `script.js` and `index.html` (currently set to +20 112 623 5681).
2. Confirm trip prices, inclusions, cancellation terms and availability.
3. Replace or approve the stock photos.
4. Add a privacy policy and terms/cancellation policy before collecting booking details.
5. This starter does not process payments or store bookings. WhatsApp is the current enquiry channel. Add a secure backend and a payment provider only when ready.

## Free publishing options
You can publish this static website using GitHub Pages, Cloudflare Pages or Netlify's free tier. You will receive a platform subdomain first; a custom domain can be connected later.
